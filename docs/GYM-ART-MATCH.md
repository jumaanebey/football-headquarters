# Gym artwork correction

The user rejected PR #73's geometric gym and requested the established building-art quality, including restoring the previous exterior. This change restores `BuildingArt` for the campus Weight Room at every existing building level and deletes `WeightRoomExterior`. The SVG room and primitive athlete drawings are removed.

The replacement is a detailed raster interior based on the bottom-right gym in the existing `starter-campus-cutouts.webp`: warm timber, charcoal walls, orange trim, black padded equipment, clear dark outlines and painted lighting. Existing single-player roster artwork is positioned inside; tapping it follows that actual roster player. No generated people are presented as roster members. Workout status and collection remain driven by the stored club state. The player images are static poses; this change does not claim authored lifting animation.

## Asset provenance and delivery

Built-in image generation was used with `public/assets/buildings/starter-campus-cutouts.webp` as the style reference. Original output: `exec-95cbebea-b2d4-4b84-9f06-448cc6ee7b71.png` in the session's generated-images directory. The project asset is `art/rooms/weight-room-interior-v2.webp`, 1536×1024, WebP quality92 without resizing. Vite imports it through `new URL(..., import.meta.url)`, emits a hashed URL, and the image is only requested when the room mounts. It is not added to the startup precache. A failed image can be retried while workout controls remain usable.
